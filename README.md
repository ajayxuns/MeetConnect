
# MeetConnect 🎥

A professional video meeting platform built using the MERN stack. Designed for teams and businesses to connect securely and collaborate in real-time.


## 📸 Preview

![Untitled - Brave 5_1_2025 7_39_48 PM](https://github.com/user-attachments/assets/e9d5d35b-0ce9-4db1-83ed-63ce086542d8)


## 🚀 Features

- 🔐 Secure video meetings
- 💬 Real-time team collaboration
- 🎨 Responsive UI with Tailwind CSS
- ⚙️ Built on the MERN stack (MongoDB, Express, React, Node.js)

## 🛠️ Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js
- Tailwind CSS

## 📦 Clone & Run Locally

```bash
git clone https://github.com/ajayxuns/MeetConnect
cd MeetConnect
npm install
npm start
```

> Make sure you have MongoDB and Node.js installed on your system.
